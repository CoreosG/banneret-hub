---
name: how-to-write-a-skill
description: Write or revise a reusable procedure for owner approval.
---

Check the effective list for an existing skill. Choose one repeatable job and a short lowercase hyphenated name. Write SKILL.md with YAML frontmatter containing name and a one-line description that tells the agent when to use it. Give concrete steps, prerequisites, stop conditions and a way to check the result. Name capabilities so the procedure works with the workspace's chosen provider. Try the instructions on an example. Propose the smallest useful change, explain why and let the owner review it. Keep credentials and personal activity out of examples.
