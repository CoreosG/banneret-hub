---
name: move-and-release-a-task
description: Move work between machines or release a task when stopping.
---

Follow the workspace's move-task prompt. Agree on the destination, push the branch and verify the remote commit. Save Goal, Done and Next outside the machine. Release the claim with handing_over and free to continue. Send the task, branch, commit and note to the destination thread. Confirm its claim before resuming. When finishing or stopping without a move, release with the actual reason and say whether another worker can continue.
