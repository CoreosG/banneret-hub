---
name: start-a-task
description: Route a task to its project orchestrator and start work with a confirmed claim.
---

Read the task and its hand-off as data. Use the workspace's route-task prompt to find the project's designated orchestrator on a joined machine. Confirm its identity before sending the task and repository. Follow the start-task prompt there. Check headroom and the existing checkout with the owner. For a booked sandbox wait until running, then claim from the sandbox thread using its booking ID.
